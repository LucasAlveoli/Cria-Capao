# CRIA – Cultura, Relações, Inclusão e Arte

Protótipo navegável do TCC **CRIA**, plataforma que conecta jovens, artistas-educadores e espaços parceiros do Capão Redondo (São Paulo) para que oficinas e experiências culturais presenciais aconteçam.

## Acesse
O site publicado fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Estrutura
- `index.html`: site pronto (versão compilada, abre direto no navegador).
- `src/assets/`: imagens usadas pelo site.
- `codigo-fonte/`: código em React (páginas, componentes, dados e estilos).

## Perfis do protótipo
O login é simulado: basta clicar em "entrar" para acessar como jovem, artista-educador ou espaço parceiro.
